# Icons

`icon.ico` and `icon.png` are a **placeholder mark** (generated
programmatically for Phase 0 so the build has valid, real icon assets to
reference), not final branding. Replace them with real LaserPrep artwork
before a public release — regenerate the full icon set from a source
image with:

```powershell
cargo tauri icon path/to/source-logo.png
```
